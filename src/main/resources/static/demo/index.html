What this demo does

60-second tour

Springtime helps a store planner decide what to reorder, for which store, and why. It combines inventory, demand, and supplier data into a ranked action list, then turns approved recommendations into purchase orders and a supplier handoff.

  1. Pick a store. Start with ST-001; every view is scoped to that store.
  2. Overview. Risk mix and priority actions, lowest days of cover first.
  3. Inventory. Search or filter to Critical/Watch. Days cover = available units ÷ average daily sales.
  4. Replenishment. Recommended units, order value, and the reason (stockout, below lead time, below safety stock, or below reorder point).
  5. Decisions. Open a run to see proposals, their status, and the resulting purchase orders.

This console is read-only. Use Swagger for the full API and write flows. Data is synthetic; it is a portfolio demo, not a production planning system.
